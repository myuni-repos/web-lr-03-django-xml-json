# Сайт для просмотра и добавления оценок студентов (Информация об успеваемости студентов по отдельным предметам XML) (вариант 10)

# Как запустить
## Склонинруйте репозиторий
`git clone <ссылка на репозиторий>`
`cd lr-03-django-xml-json`

## Подготовка к запуску
### Создание venv
`python3 -m venv venv`
`source venv/bin/activate`

### Установка зависимостей
`pip install -r requirements.txt`

## Запуск
`python manage.py runserver`
Откройте браузер и перейдите по адресу:
http://127.0.0.1:8000/
